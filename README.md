# 🍌 FruityToons AI – Funny Fruit Cartoon Video Maker 🍍

**FruityToons AI** is a lightweight, mobile-first Progressive Web Application (PWA) designed to help creators, YouTubers, and TikTokers generate funny, animated talking-fruit cartoon videos directly from their mobile phones or web browsers.

---

## ✨ Features

- 🎭 **Fruit Character Library:** Preset characters including Bobo the Banana, Mimo the Mango, Stella the Strawberry, Kiki the Pineapple, Wally the Watermelon, and custom character creation.
- 📜 **Synced AI Script Generator:** Enter any story prompt or comedy topic to automatically build matching multi-scene scripts and dialogue.
- 🎬 **Interactive Video Studio:** Real-time animated canvas preview, expression toggles, speech synthesis, karaoke subtitles, and sound effects.
- 📐 **Multi-Aspect Ratio:** Export and render videos in Portrait (9:16 for TikTok/Shorts/Reels), Square (1:1), or Landscape (16:9).
- 📱 **Mobile & Desktop Friendly:** Optimized for touch devices (Android/iOS) and desktop browsers.
- 💾 **Local Storage & Offline Mode:** Save drafts, custom fruit characters, and video projects directly inside your browser.

---

## 🚀 Quick Start & Deployment

### 1. Run Locally
1. Download or clone this repository.
2. Open `index.html` in any web browser (Google Chrome, Firefox, Safari, or Microsoft Edge).

### 2. Deploy to GitHub Pages (Free Hosting)
1. Fork or push this repository to your GitHub account.
2. Go to **Repository Settings** > **Pages**.
3. Under **Build and Deployment**, set the source branch to `main` (or `master`) and directory to `/ (root)`.
4. Click **Save**. Your app will be live at `https://<your-username>.github.io/<repository-name>/`.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS (via CDN), Vanilla JavaScript (ES6+)
- **Storage:** HTML5 Web Storage (`localStorage` / `IndexedDB`)
- **Animation Engine:** HTML5 Canvas API + Web Speech API (SpeechSynthesis)
- **Deployment:** GitHub Pages / Any static hosting service
